# Codex: локальная работа агентов на Windows

Рабочие инструменты и решения для Codex и Antigravity. Первый сохранённый
результат — контроль запуска процессов и ограниченная диагностика памяти
после повторных падений VS Code 13 ноября 2026 года.

Системное исчерпание Commit подтверждено. Конкретный процесс, создавший пик
памяти в тот день, установить не удалось. Сохранённое решение ограничивает
запуски агентов и собирает данные для следующего возможного инцидента;
устранение первопричины крашей ещё не доказано.

- [Суть инцидента, факты, решения и ограничения](docs/windows-execution/incident-2026-11-13.md).
- [Исходники, сборка, проверки и восстановление](windows-execution/README.md).
- [Контрольные суммы принятого снимка](windows-execution/snapshot.json).

В снимке: общий исполнитель команд на Windows Job Objects, нативные hooks
Codex/Antigravity, PerfMon и обслуживание хранения. Обычная диагностика хранится
до 7 суток, инциденты — до 30; общий бюджет — 512 МиБ.

Репозиторий хранит исходники для дальнейшего сопровождения. Действующая
установка находится отдельно в пользовательском каталоге `.agents/windows-execution`.
Автоматической синхронизации и установки из Git нет. Будущие изменения сначала
делаются здесь, проверяются, затем отдельно устанавливаются с учётом нативного
доверия к hooks и сохранённого отката.

Решение остаётся на наблюдении в обычной работе. Стрессовые тесты не проводились.
Согласованное направление — не добавлять новые слои, упрощать по конкретным
повторяющимся затруднениям. Две версии бинарника сохранены как технический долг
принятой установки; их объединение отложено до планового изменения.

Публичный снимок содержит исходники, тесты и пример политики. Сырые журналы,
дампы, базы и история чатов, конфигурация аккаунтов, операторский SID, резервные
копии пользовательских настроек и установленные exe в Git не включены.
