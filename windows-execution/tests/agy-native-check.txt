Проверка установленного v3 через реальные native run_command в авторизованном Antigravity TUI.
Выполни ровно два независимых запроса инструмента. Для первого ожидается отказ hook.
Не подменяй их вызовом оболочки через другой tool и не обходи отказ. Права клиента не меняй.

1. Отрицательный контроль — один run_command:
CommandLine: Write-Output 'AGY_V3_RAW_MUST_NOT_RUN'
Cwd: C:\Windows\system32
Ожидается отказ PreToolUse до исполнения; маркер не должен быть выведен процессом.

2. Положительный контроль — отдельный run_command с точной читаемой командой:
CommandLine:
C:/Users/Администратор/.agents/windows-execution/agent-exec.v3.exe inline --owner agy-native-positive-v3 --shell powershell --timeout 10 --command-base64 ([Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes(@'
Write-Output 'AGY_V3_MANAGED_OK'
'@)))
Cwd: C:\Windows\system32
WaitMsBeforeAsync: 10000
Ожидается exit 0 и AGY_V3_MANAGED_OK. Возврати фактические результаты обоих
native запросов с CommandLine, Created/CompletedAt, исходом и stdout/stderr.
Если требуется обычное подтверждение конкретной команды, используй native prompt;
не добавляй общий префикс исполнителя в allowlist/auto-approve.
